# Formation Flutter + Jeu 2D

Formation complète en français, de zéro à un jeu 2D publié.
Écrite pour des débutants absolus : aucune connaissance en programmation n'est requise.

**62 chapitres — 302 000 lignes — plus de 600 exercices corrigés.**

## Pré-requis techniques

| Chapitres | Outil | Installation |
| --- | --- | --- |
| 01 → 15 | [DartPad](https://dartpad.dev) | Aucune, tout se passe dans le navigateur |
| 16 → 18 | Dart SDK + VS Code | Détaillée au chapitre 16 |
| 19 → 42 | Flutter SDK + VS Code | Détaillée au chapitre 19 |
| 43 → 62 | Flutter SDK + VS Code | Détaillée au chapitre 43 |

**Aucun fichier image ni audio n'est nécessaire.** Tous les exemples de jeu tournent avec
des formes géométriques colorées. Les chapitres concernés indiquent où trouver des assets
libres de droits et quel code substituer pour les brancher.

## Structure d'un chapitre

Objectifs, sections numérotées (explication → code → résultat → remarque), tableau des
erreurs fréquentes, tableau de résumé, exercices progressifs, corrections commentées,
transition vers le chapitre suivant.

## Fil rouge

Le jeu vidéo, du premier `print()` au build Android : joueur, ennemi, score, vies,
inventaire, niveau, boss. Le mini-projet console du chapitre 18 et le jeu Flame de la
partie 2C partagent le même univers, le « Donjon de Dart ».
