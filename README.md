## Suite du programme

- **PARTIE 1B — Flutter** : widgets, layouts, navigation, formulaires, thèmes, gestion d'état, API REST, stockage local
- **PARTIE 1C — Mini-projets Flutter** : 8 applications, de la carte de profil à l'application météo
- **PARTIE 2A — Introduction au développement de jeux** : game loop, FPS, delta time, sprites, collisions
- **PARTIE 2B — Flame** : le moteur de jeu 2D de Flutter
- **PARTIE 2C — Jeu complet** : menu, joueur, ennemis, score, niveaux, boss, sons, sauvegarde
- **PARTIE 2D — Projet final** : cahier des charges, architecture, tests, build Android et Web

## Pré-requis

- Chapitres 01 à 15 : un navigateur et [DartPad](https://dartpad.dev). Rien à installer.
- Chapitres 16 à 18 : Dart SDK et VS Code. L'installation est détaillée au chapitre 16.

## Structure d'un chapitre

Chaque chapitre est autonome et suit toujours le même plan : objectifs, sections numérotées
(explication → code → résultat → remarque), tableau des erreurs fréquentes, tableau de
résumé, exercices progressifs, corrections commentées, transition vers le chapitre suivant.

## Conventions

Le fil rouge de la formation est le jeu vidéo : joueur, ennemi, score, vies, inventaire,
niveau, boss. Chaque notion apprise en Dart est réutilisée dans le jeu 2D de la partie 2.
